# bcl principles
1. Live tracker = truth. bcl cmds only; no hand edits, no internals. Page shows real status.
2. Delete first. Order: delete, simplify, optimise, automate. New step replaces >= what it adds.
3. Root cause. Fix first break. Shared premise across fixes: attack premise.
4. Blast radius. Check dependents before change.
5. Independent lanes only. Max 4. Dependent: next round.
6. Gate is law. Exceptions: Guru only. bcl bug: hotfix lane.
7. Prove it. Count only after live check on installed build.
8. Ship every round. Release verified fixes; 16 only for merge.
9. Token budget. Fresh lean sessions, short reports, read deltas, cap loops.
10. Test behaviour. Fails without fix; asserts what user sees.
11. Every word = token. Fewest high-signal words. Min prose. Grammar optional.
